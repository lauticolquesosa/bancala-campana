# Bancala — Mucho más que un banco

Campaña de UCASAL Sustentable para cuidar los bancos de los espacios comunes de la Facultad. Protagonista: Quito, el banquito.

| Carpeta | Contenido |
|---|---|
| `Presentacion/` | Todo el proyecto de la campaña: presentación, piezas, concepto, recursos, material original, scripts y fuente de producción. Ver `Presentacion/LEEME.md`. |
| `Pagina Web/` | Sitio web de la campaña (estático: HTML + CSS + Three.js + GSAP + Lenis), con Quito en 3D en el home. Ver `Pagina Web/README.md`. |
